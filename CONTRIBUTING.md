# Contributing

Thanks for your interest in contributing to Online Meeting List!

This document outlines the process for reporting issues, proposing changes, and submitting pull requests.

## Code of conduct

Please follow the project's `CODE_OF_CONDUCT.md` (Contributor Covenant). Be respectful and constructive.

## How to contribute

1. Fork the repository and create a branch for your change. Use a descriptive branch name, e.g. `fix/sidebar-sticky` or `feat/add-pagination`.
2. Make small, focused commits. Use conventional commit messages where possible (e.g., `fix: correct layout bug`, `feat: add results header`).
3. Run the development server and tests (if present) locally:

```bash
pnpm install
pnpm dev
```

4. Open a pull request against the `refactor/2025-glowup` branch (or `main` if that's your target). Include a short explanation of the problem, the proposed change, and the testing steps.

## Pull request checklist

- [ ] The code builds and runs locally
- [ ] The change is covered by tests (if applicable)
- [ ] The change has a short description in the PR
- [ ] Commit messages are clear and atomic

## Reporting security issues

If you find a security vulnerability, please do not open a public issue. Instead, contact the repository owner directly via the email listed on their GitHub profile or open a private issue (if available).

Thanks for helping improve the project!
